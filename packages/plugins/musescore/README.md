# MuseScore Plugin (StageSync)

Wtyczka QML dla MuseScore Studio, umożliwiająca komunikację ze StageSync.

## ⚠️ Status

Projekt w fazie inicjalizacji. Wtyczka obecnie posiada jedynie szkielet kodu (boilerplate) i nie realizuje jeszcze pełnej funkcjonalności eksportu danych.

## 🛠️ Rozwój

Wtyczka ma docelowo umożliwić:

- Eksport struktury partytury do formatu StageSync.
- Integrację z silnikiem transportu StageSync.
