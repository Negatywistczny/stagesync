# 🎼 @stagesync/plugin-musescore — Wtyczka MuseScore

Wtyczka QML dla oprogramowania MuseScore Studio, umożliwiająca dwukierunkową komunikację oraz eksport partytur ze StageSync.

## ⚠️ Status projektu

Projekt w fazie inicjalizacji. Wtyczka obecnie posiada jedynie szkielet kodu (boilerplate) i nie realizuje jeszcze pełnej funkcjonalności eksportu danych.

## 📁 Struktura i rozwój

Wtyczka ma docelowo umożliwić:
- Eksport struktury partytury do formatu StageSync (v5 project / musicXML).
- Synchroniczną integrację z silnikiem transportu StageSync za pomocą WebSockets.
