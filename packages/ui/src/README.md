# 🎨 @stagesync/ui/src — Komponenty Prezentacyjne i Tokeny

Katalog `src/` zawiera zestaw prezentacyjnych komponentów React oraz arkusze stylów CSS Modules Design Systemu.

## 📁 Struktura i przeznaczenie subkatalogów

- **`components/`** — Komponenty bez logiki biznesowej (`Button`, `Input`, `Select`, `Badge`, `SegmentedControl`, `Slider`).
- **`styles/`** — Pliki CSS Modules oraz definicje klas stanów interakcji.
- **`tokens/`** — Definicje zmiennych CSS (`--ss-*`) odpowiedzialnych za kolory, typografię, promienie i siatkę przestrzenią 4pt/8pt.
